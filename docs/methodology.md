# Methodology

## 1. 基本的な考え方

東京七十二候は、古典七十二候をそのまま東京へ移植するのではなく、現代の東京で観察可能な生物・自然現象を約5日ごとの枠に配置する編集的な暦である。

二十四節気は太陽黄経に基づく比較的安定した骨格として残し、七十二候は「動いていく生物の暦」として扱う。

> 動かない太陽の暦 × 動いていく生物の暦

## 2. 選定基準

- 人が視覚、聴覚、嗅覚などで気づけること
- 東京のどこかで現実的に出会えること
- 数日〜数週間程度の季節性があること
- 時期を公開資料、観察記録、気象条件等から推定できること
- 年間全体で対象や感覚が偏りすぎないこと
- 現代の都市生活との接点があること
- 園芸植物だけに過度に依存しないこと
- 一部地域に限られる場合は、その地域性を明示できること

## 3. 1対象1候

原則として、同一の生物・現象を複数の候に使わない。開始、最盛、終期のすべてを別候にするのではなく、季節情報として最も価値が高い局面を一つ選ぶ。

優先順位は概ね、開始 → 最盛 → 終期。

終期、聞き納め、散り際などは、七十二候本体ではなく、将来の動的な推薦・通知で扱うことを想定する。

## 4. 固定区間と実際の季節

`start_day` / `end_day` は暦上の代表区間であり、自然現象が毎年その5日間に必ず発生するという意味ではない。実際の季節現象は気温、積算温度、降水、日照、都市ヒートアイランド、地形、土地被覆、個体差・種差などによって前後する。

将来的には「2026年の東京七十二候」のように、固定暦に実観測・予測を重ねることを目指す。

## 5. 条件依存型の現象

虹、夕立、カタツムリ、キノコなど、固定日付より当日の気象条件の方が重要な現象は、七十二候本体とは分離し、動的推薦に適した現象として扱う。

## 6. 地域差

東京は都心部から多摩丘陵・山地まで環境差が大きい。同じ候でも実際の到来日は場所によって異なりうる。固定候は東京都全体の代表的な編集枠であり、将来の実装では地域・現在地による出し分けを前提とする。

## 7. 根拠の管理

候の根拠には、東京都・都立公園、気象庁、国立天文台、自然観察団体等の公開情報を用いる。外部資料そのものを再配布するのではなく、`sources/source_registry.csv` に出典URL、観測日、採用判断との関係を記録する。
