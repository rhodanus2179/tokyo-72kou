# Sources

東京七十二候では、公開情報をもとに各候の時期・観察可能性を検討する。

主な情報源は、東京都・東京都公園協会、気象庁、国立天文台、日本野鳥の会等の観察記録、その他東京での観察時期を確認できる公開資料。

出典は [`../sources/source_registry.csv`](../sources/source_registry.csv) に正規化して収録する。

## Current status

v0.4 の現象72件は一旦の基準版として固定しているが、出典整理は継続中である。

2026-08-27 時点で、これまでの検討過程で個別に確認した資料を `source_registry.csv` に移し、東京都公園協会、気象庁、国立天文台、東京ズーネット、野鳥観察資料等の根拠を登録した。

レジストリにまだ資料が紐づいていない候は「根拠がない」という意味ではなく、検討時に利用した資料がまだ正規化・移植されていない、または追加検証を要する状態を含む。

## Registry policy

- `kou_id` で [`../data/tokyo_72kou.csv`](../data/tokyo_72kou.csv) の候と接続する。
- 同じ候に複数の資料を登録してよい。
- `observed_date` は個別観察記録の日付が明示されている場合のみ記入する。
- 平年値、一般的な花期・飛来期等を示す資料では `observed_date` を空欄にし、`note` に根拠の内容を記載する。
- URLだけでなく、何を確認するために参照したかを `note` に残す。
- 外部資料の本文・画像等は原則として本リポジトリに複製しない。
- 候の5日間は固定された生物学的発生日ではなく、現代東京の季節を表す代表区間として扱う。

## Evidence quality

出典が1件あることだけで候を確定的な科学的観測値として扱わない。年変動、地域差、都市部／多摩部の差、植栽依存性などが大きい現象では、複数年・複数地点の資料を追加していく。

特に開始時期を採用した候では、単年の観察日と平年・一般時期を区別して管理する。
