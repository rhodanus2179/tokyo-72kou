# Sources

東京七十二候では、公開情報をもとに各候の時期・観察可能性を検討する。

主な情報源は、東京都・東京都公園協会、気象庁、国立天文台、日本野鳥の会等の観察記録、その他東京での観察時期を確認できる公開資料。

出典は [`../sources/source_registry.csv`](../sources/source_registry.csv) に順次正規化して収録する。

初期コミットでは72候データの公開を先行し、出典レジストリは未完である。候ごとの出典が整理されるまでは、各候の評価を確定的な科学的観測値として扱わないこと。

外部資料の本文・画像等は原則として本リポジトリに複製せず、URLと参照内容を記録する。
