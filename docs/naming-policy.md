# Naming policy

候名は、学術的なラベルでも古語の模倣でもなく、**短く、景色が浮かび、読み上げても自然な日本語**を目指す。

- 現象が分かることを最優先する
- 漢字表記には多少の詩情を許す
- 難読語は `reading` を必ず付す
- 「咲く」「鳴く」「香る」「染む」だけに偏らないよう、動詞にリズムを持たせる
- ただし、無理にすべて異なる動詞にはしない
- 生物名を古名・漢字名にする場合でも、読みで一般名が分かるようにする
- 過度な擬古文や意味の取りにくい造語は避ける

例：`蕗の薹土を割る`、`蜩夕べを告ぐ`、`彼岸花野に立つ`、`紅葉森燃ゆ`、`銀杏街を照らす`。
